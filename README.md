# GuacamaIA: Tourism Demand Intelligence Dashboard

## Business Problem
Tourism companies often struggle to accurately predict demand. This leads to inefficient pricing strategies, high cancellation rates, and poor resource allocation.

## Solution
This project builds an end-to-end data analytics solution to:

- Analyze historical booking demand
- Identify trends and seasonality
- Forecast future demand using time series models
- Support data-driven decision-making

## Tech Stack
- SQL (data extraction and aggregation)
- Python (data analysis and forecasting)
- Power BI (dashboard and visualization)

## Dataset
- Source: Hotel Booking Demand Dataset (Kaggle)
- Features include:
  - Booking dates
  - Customer country
  - Price (ADR)
  - Cancellation status
